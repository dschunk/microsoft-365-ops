# Roadmap

SchunkOps Microsoft 365 grows through small, inspectable capabilities rather than an all-powerful tenant script.

## Next

- PIM eligibility and activation inventory
- Enterprise application credential-expiry report
- OAuth consent and application-permission audit
- Mail flow connector and transport-rule inventory
- SharePoint and OneDrive external-sharing report
- Teams policy assignment drift report
- Secure Score control snapshot
- Service health and Message Center digest

## Engineering milestones

- Pester unit coverage with mocked Graph and Exchange responses
- Module packaging with stable object schemas
- JSON Schema for snapshot manifests
- Signed release artifacts and provenance attestations
- Sample sanitized fixtures for contribution testing
- PowerShell Gallery publication after code signing and release automation are ready

## Proposal standard

A proposed tool should name the operational decision, data source, least-privilege permissions, license dependency, output schema, expected failure modes, sensitive fields, and a safe test strategy.
