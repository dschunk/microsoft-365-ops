# Support

This is a community toolkit, not a Microsoft product or a managed service.

- Use GitHub Issues for reproducible bugs and focused feature requests.
- Use Discussions for operational patterns and questions when enabled.
- Include PowerShell version, module versions, the command used, sanitized output, required licenses, and the exact error.
- Do not post tenant names, domains, identities, object IDs, credentials, tokens, or unredacted exports.

For Microsoft service incidents or product defects, use your organization's official Microsoft support path.
